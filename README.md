# Taller virtual de motos · MotoMod

La versión actual del producto está en [`ai-workshop/`](ai-workshop/README.md): homepage, catálogo de motos, cuentas opcionales, chat con Gemini y edición real con Stability AI. En el taller, el usuario pinta la pieza o zona que quiere modificar y esa selección se envía como máscara de inpainting.

Para instalar, ejecutar o desplegar la aplicación sigue las instrucciones de [`ai-workshop/README.md`](ai-workshop/README.md). Las carpetas `backend/` y `frontend/` de esta raíz corresponden al prototipo inicial con integraciones anteriores; ya no son la versión recomendada.
